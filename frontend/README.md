# TrackIdea – frontend

React 19 + Vite. Instrukcja uruchomienia całości i scenariusze demo są w [głównym README](../README.md).

```bash
npm install
npm run dev     # http://localhost:5173, /api trafia do backendu na porcie 8080
npm run build   # wersja produkcyjna w dist/
npm run lint
```

Na produkcji adres backendu można wskazać zmienną `VITE_API_URL`.
